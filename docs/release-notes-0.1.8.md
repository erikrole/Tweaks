# Tweaks 0.1.8

## Signed app updates

- Check for new releases automatically on normal launches, or use Check for Updates in the Tweaks app menu while Settings is open.
- Download and verify signed ZIP updates before replacing the app, with recovery if relaunch fails.
- Preserve existing save and busy safeguards while preparing and relaunching updates.
- Require macOS 27 or later and Apple Silicon.
